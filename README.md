## 📦 Open Source

### [express-audit-trail](https://github.com/Clizco/express-audit-trail)

[![npm](https://img.shields.io/npm/v/express-audit-trail?logo=npm&label=npm)](https://www.npmjs.com/package/express-audit-trail)
[![CI](https://github.com/Clizco/express-audit-trail/actions/workflows/ci.yml/badge.svg)](https://github.com/Clizco/express-audit-trail/actions/workflows/ci.yml)

A lightweight, TypeScript-friendly audit logging middleware for Express.js applications.

**Features:**
- Automatic tracking of create, update, and delete operations
- User, timestamp, and request context tracking
- Sensitive information redaction
- Pluggable storage adapters
- Zero runtime dependencies

```bash
npm install express-audit-trail
```

Developed from real production requirements and designed for reusable backend architecture.
